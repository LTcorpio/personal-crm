# 个人 CRM 系统使用指南

欢迎使用个人 CRM 系统！本系统记录了自己一生中所结识的人。本人在日常生活中有收集信息的习惯，本系统尽可能根据已掌握的各类文件或资料，根据标签对人物进行分类，并列出已知人员的已知信息。

## 💡 主要功能

### 1. 人脉管理
* **按标签查看**：本系统核心页面，管理人脉信息。右上角“新增联系人”可填入人员信息，可切换三种显示模式。左侧“标签”根据已填写的人员信息中的“标签”信息自动生成，点击对应标签可筛选对应人员。搜索模块可以指定搜索范围，根据搜索内容匹配相关字段值，搜索结果将只包含已勾选的字段。在列表模式下，可以自定义表头显示的字段以及顺序。人脸数据强依赖于Immich中已存在的人脸，如缺失人脸信息，则先上传至少一张包含该人物的照片，在Immich中完成标注后获取其UUID并填入联系人档案。
* **按主题查看**：可根据不同的主题对人员进行分类，适用于非强行关联的情形，如喜爱的人、黑名单等。主体功能与“按标签查看”保持一致。在“编辑主题”的弹窗中，填写主题成员时，若未指定人员id，系统会自动匹配姓名，如有重名的情况请务必填写id。如该人员未录入系统，则不会在列表中显示，页面中显示“当前主题中有 XX 位成员未匹配到联系人档案”。
* **生日信息统计**：根据填写人员的阳历生日信息，生成“生日日历图”，可视化展示全年每天有哪些人过生日，图表下方展示对应月份的生日名单，点击姓名可查看联系人详细档案。

### 2. 亲戚计算器
该功能来源于“[中国亲戚关系计算器](https://passer-by.com/relationship/)”开源项目。

## 🛠️ 快捷操作
* 点击页面顶部的 **“新增联系人”** 可以快速添加新成员。
* 切换右侧的视图按钮（卡片、精简、列表）可以改变人脉的展现形式。


## 其他说明
以下列出部分数据来源，请注意：
1. 不保证所有数据来源可靠，所有数据源均仅供参考。
2. 部分字段，尤其是所在地区、详细地址、联系方式等，以及社交平台上能够获取到的信息，均为对应时期所收集的信息，可能随个人生活变动而改变，不保证时效性。如初中时期是2014-2017年，那么对应的信息是在这段时期收集的。
3. 一些字段值在收集或整理的过程中可能也会有错误，敬请谅解。
4. 数据收集往往是多方来源综合整理，不只局限于下方列出的内容，一些信息是有形的、可以检索到的，一些信息则是根据回忆进行补充的，一些信息也可以是根据已有信息所推断出来的。
